# Next.js template

This is a Next.js template with shadcn/ui.

## Instalar en un celular

El sistema se puede instalar desde Chrome cuando está publicado y se accede por HTTPS. En Android, abre la dirección del sistema en Chrome, toca el menú ⋮ y selecciona **Instalar aplicación** o **Agregar a pantalla principal**. Chrome usará el icono del sistema para crear el acceso directo.

En desarrollo, Chrome también permite probarlo desde `localhost`.

## Adding components

To add components to your app, run the following command:

```bash
npx shadcn@latest add button
```

This will place the ui components in the `components` directory.

## Using components

To use the components in your app, import them as follows:

```tsx
import { Button } from "@/components/ui/button";
```
